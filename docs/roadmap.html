Roadmap

What we're working on and what comes next. Plans can change, and new features usually land on macOS first, then on Windows and Linux.

What's already shipped Suggest a feature

Now

OpenRouter and custom providers

Run Claude Code through OpenRouter or any Anthropic-compatible endpoint, with the key kept in your system keychain.

winget and Flathub

Install and update PullYard with your usual package manager on Windows and Linux. Homebrew is already here: brew install --cask pullyard/tap/pullyard.

Next

Codex support

Chat with Codex next to your pull request and use it for Fix, with its own sessions and history.

More agents

Gemini CLI and other agents through the open Agent Client Protocol.

Choose your agent

Fix with Claude Code, Codex or another agent from the same sheet.

Isolated worktrees

Each fix runs in its own git worktree, so your working copy stays untouched.

AI review drafts

An agent reads the diff and drafts inline review comments. You pick which ones to post.

Close the loop

After a fix: commit, push, reply to the threads it addressed and resolve them.

Full review for GitLab and Bitbucket

Changed files, comments, approvals and merging for GitLab merge requests and Bitbucket pull requests, like on GitHub.

Create pull requests

Open a PR from a branch inside the app, with a description your agent drafts.

Later

Compare agents side by side

Run the same task with two agents and keep the better diff.

Command palette

Jump to any PR, repository or action with ⌘K.

Usage across agents

One place for plan limits and spend for every agent you use.

Signed and notarized apps

No more Gatekeeper or SmartScreen warnings on first launch.
