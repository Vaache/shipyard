Why Shipyard

Everything you open GitHub for.
Nothing you don't.

A browser tab with GitHub can eat a gigabyte just to show one diff. Shipyard is a SwiftUI app that does the daily review work and stays out of the way.

Native and instant

Built with SwiftUI and AppKit. Diffs with thousands of lines scroll smoothly, with sticky file headers.

Full pull request review

Conversation, review threads, commits, checks and files. Comment, approve, request changes, merge — and see stacked PRs as one chain.

Fix with Claude Code

One click sends review feedback to Claude Code. Uses the reviewer's “Fix prompt” if there is one, or writes it for you.

Inbox that keeps up

Notifications, issues and review requests with a menu bar badge, so you know when someone is waiting on you.

Repos and projects

Browse repository files with syntax highlighting, and see your GitHub Projects boards without leaving the app.

Your keys stay yours

Sign in with the GitHub CLI, a personal token or Device Flow. Tokens live in the macOS Keychain. No servers in between.

Claude Code workspace

Review it, fix it, ship it — in one window.

Shipyard has a built-in chat for the official Claude Code CLI, next to the PR, the changed files and the branch it's working on.

  • Sessions by project. History grouped by folder and branch, with the PR each session opened.
  • Model, effort and mode. Switch on the fly, approve tool calls inline, see diffs of every edit.
  • Idle sessions sleep. Chats you left in the morning free their memory and wake up on the next message.
  • Usage at a glance. Context window and plan limits in one overlay, like the CLI shows.
  • Personal and work accounts. Keep separate Claude sign-ins and switch between them.

Install

Up and running in a minute.

Shipyard isn't notarized yet, so macOS asks once before the first launch.

Download

Get the latest universal DMG from GitHub Releases.

Drag to Applications

Open the DMG and drop Shipyard into your Applications folder.

Allow first launch

System Settings → Privacy & Security → Open Anyway. The DMG has a short guide, or run the command below.

xattr -dr com.apple.quarantine /Applications/Shipyard.app

Questions

Is this an official GitHub or Anthropic app?

No. Shipyard is an independent open-source project. It uses the public GitHub API and runs the official Claude Code CLI that you install yourself.

Where does my data go?

Straight from your Mac to api.github.com. Your token is stored in the macOS Keychain. Shipyard has no backend and no analytics.

Do I need Claude Code?

No. Everything GitHub-related works without it. The Claude Code workspace and “Fix with Claude Code” light up once the CLI is installed and signed in.

How do I update?

Choose Shipyard → Check for Updates…. Shipyard downloads the new release from GitHub, installs it and restarts. It also checks once a day on its own; you can turn that off in Settings.

How does sign-in to Claude work?

Shipyard never sees your Claude credentials. It runs claude auth login, which opens the official sign-in page in your browser.
