Why PullYard

The parts of GitHub
you use every day.

GitHub in a browser tab can take up a gigabyte of memory to show a single diff. PullYard is a small native app for everyday review work.

Native and fast

SwiftUI on macOS, WinUI 3 on Windows, GTK 4 on Linux. Diffs with thousands of lines scroll without stutter, and file headers stay pinned.

Full pull request review

Conversation, review threads, commits, checks and files. Comment, approve and merge, follow stacked PRs as one chain, and re-request review in one click after you push.

Fix with Claude Code

One click sends review feedback to Claude Code. If the reviewer left a “Fix prompt”, PullYard uses it; otherwise it writes one from the comments.

Fresh without reloading

Pull requests refresh every 30 seconds and new ones appear at the top. Pull down on a list or press ⌘R / Ctrl+R to refresh right away. A menu bar badge on the Mac, or a tray icon on Windows, counts the reviews waiting on you.

Repos and projects

Browse repository files with syntax highlighting and open your GitHub Projects boards in the same window.

Private by default

Sign in with the GitHub CLI, a personal token or Device Flow. Your token is kept in the system keychain, and PullYard talks to GitHub directly with no server of its own.

Claude Code workspace

Review and fix in the same window.

PullYard has a chat for the official Claude Code CLI built in, right next to the PR, its changed files and the branch Claude is working on.

  • Sessions by project. History is grouped by folder and branch, and shows the PR for each session.
  • Model, effort and mode. Change them mid-session, approve tool calls in the chat and see a diff for every edit.
  • Idle sessions sleep. A chat you left in the morning frees its memory and picks up again on your next message.
  • Usage overlay. Context window and plan limits in one place, the same numbers the CLI shows.
  • Personal and work accounts. Keep separate Claude sign-ins and switch between them.

Install

Install

Pick your system. Each one gets its own native build of the same app.

macOS

PullYard isn't notarized yet, so macOS asks once before the first launch. After that, updates install from inside the app.

Download

Get the latest DMG from GitHub Releases. It runs on Apple Silicon and Intel.

Drag to Applications

Open the DMG and drop PullYard into your Applications folder.

Allow first launch

Go to System Settings → Privacy & Security → Open Anyway, or run the command below. You only do this once.

xattr -dr com.apple.quarantine /Applications/PullYard.app
Homebrewbrew install --cask pullyard/tap/pullyard
macOS 14 or laterApple Silicon or IntelOptional: GitHub CLIOptional: Claude Code CLI

Windows

PullYard isn't code-signed yet, so SmartScreen asks once before the first launch. After that, the installed app updates itself.

Download

Get the setup for your PC, x64 or ARM64. It installs just for you, no admin rights needed.

Run the setup

If SmartScreen says it protected your PC, click More info → Run anyway. You only do this once.

Or go portable

Prefer no installer? Unzip the portable build anywhere and run PullYard.exe. It opens the release page when there's an update.

PortableExpand-Archive .\PullYard-windows-x64-portable.zip -DestinationPath .\PullYard

Linux

Three ways to install, all for x86_64. Pick the one that fits your distribution.

.deb package

For Ubuntu 24.04 or later, Debian and their derivatives. apt pulls in GTK 4, libadwaita and the other libraries.

Flatpak

Works on any distribution. It uses the GNOME runtime from Flathub and runs git, gh and claude from your system.

Tarball

A portable build for systems with GTK 4.14 or later. The install script puts it in ~/.local, and it updates itself.

Questions

Is this an official GitHub or Anthropic app?

No. PullYard is an independent open-source project. It uses the public GitHub API and runs the official Claude Code CLI, which you install yourself.

Do I need Claude Code?

No. All the GitHub features work without it. The Claude Code workspace and “Fix with Claude Code” turn on once the CLI is installed and signed in.

How does sign-in to Claude work?

PullYard never sees your Claude credentials. It runs claude auth login, which opens the official sign-in page in your browser.

Where does my data go?

From your computer straight to api.github.com. Your token is stored in the macOS Keychain, Windows Credential Manager or the Secret Service keyring on Linux. PullYard has no backend and no analytics.

How do I update?

PullYard checks GitHub for a new release every 6 hours; you can turn that off in Settings. On macOS, choose PullYard → Check for Updates… any time: it downloads the release, replaces itself and restarts, so there's no disk image to open. The Windows installer build and the Linux tarball update themselves the same way. The Windows portable build, the .deb and the Flatpak open the release page so you can grab the new file.

How fresh is what I see?

Pull request lists, the open pull request and notifications refresh every 30 seconds while PullYard is in front, and again as soon as you switch back to it. The footer shows when the list was last updated. Pull down on a list or press ⌘R (Ctrl+R on Windows and Linux) to refresh now. You can change the interval in Settings.
